CRITICAL: Extract structured FACTS into payload fields. DO NOT invent titles.
Titles are generated deterministically from templates after extraction.

=== CANONICAL SIGNAL TYPES ===

1. position_limit_breach
   - Description: Asset position exceeds configured limit
   - REQUIRED fields: asset, current_position, limit
   - Optional: duration_hours, breach_percent, entity, evidence_text
   - Example source: "USD cash position stands at $15.2 million, exceeding our $10M limit"
   - Extract: { asset: "USD cash", current_position: "$15.2M", limit: "$10M" }

2. market_volatility_spike
   - Description: Market volatility exceeds threshold
   - REQUIRED fields: asset, volatility, threshold
   - Optional: window_hours, measure_type, evidence_text
   - Example source: "VIX at 35, significantly above 20 threshold"
   - Extract: { asset: "VIX", volatility: "35", threshold: "20" }

3. counterparty_credit_downgrade
   - Description: Counterparty credit rating downgraded
   - REQUIRED fields: counterparty, previous_rating, new_rating
   - Optional: rating_agency, exposure_usd, evidence_text
   - Example source: "Moody's downgraded Bank ABC from A2 to Baa1"
   - Extract: { counterparty: "Bank ABC", previous_rating: "A2", new_rating: "Baa1", rating_agency: "Moody's" }

4. liquidity_threshold_breach
   - Description: Asset liquidity falls below required threshold
   - REQUIRED fields: entity, current_ratio, threshold
   - Optional: asset, shortfall_usd, currency, evidence_text
   - Example source: "Operating liquidity ratio at 0.12, below 0.20 minimum"
   - Extract: { entity: "Operating Account", current_ratio: "0.12", threshold: "0.20" }

5. fx_exposure_breach
   - Description: Foreign exchange exposure exceeds approved limit
   - REQUIRED fields: currency_pair, current_exposure, limit, direction
   - Optional: breach_percent, hedge_recommendation, evidence_text
   - Example source: "EUR/USD long exposure of $12M exceeds $10M limit"
   - Extract: { currency_pair: "EUR/USD", current_exposure: "$12M", limit: "$10M", direction: "long" }

6. cash_forecast_variance
   - Description: Actual cash position deviates significantly from forecast
   - REQUIRED fields: account, actual, forecast, variance_percent
   - Optional: variance_direction, forecast_date, root_cause, evidence_text
   - Example source: "Actual cash $3.2M vs forecast $5M, -36% variance"
   - Extract: { account: "Main Operating", actual: "$3.2M", forecast: "$5M", variance_percent: "-36%" }

7. covenant_breach
   - Description: Financial covenant threshold breached or at risk
   - REQUIRED fields: covenant_name, actual_ratio, required_ratio
   - Optional: covenant_type, lender, facility, cure_period_days, evidence_text
   - Example source: "DSCR at 1.18x versus 1.25x covenant requirement"
   - Extract: { covenant_name: "DSCR", actual_ratio: "1.18x", required_ratio: "1.25x" }

8. settlement_failure
   - Description: Trade settlement failed or is at risk of failure
   - REQUIRED fields: counterparty, amount, failure_reason
   - Optional: trade_id, asset, settlement_date, evidence_text
   - Example source: "Trade #12345 with Broker XYZ failed, $1.5M, insufficient funds"
   - Extract: { counterparty: "Broker XYZ", amount: "$1.5M", failure_reason: "insufficient_funds", trade_id: "12345" }

9. settlement_rail_shortfall
   - Description: Insufficient funds available on a settlement rail
   - REQUIRED fields: rail, shortfall, coverage_ratio
   - Optional: required, available, fragmentation_ratio, restricted_cash, root_cause, evidence_text
   - Example source: "Fedwire balance $12M insufficient for $15M payments, 0.80 coverage"
   - Extract: { rail: "Fedwire", shortfall: "$3M", coverage_ratio: "0.80", available: "$12M", required: "$15M" }

10. debt_maturity_approaching
    - Description: Debt facility approaching maturity requiring refinancing decision
    - REQUIRED fields: facility, amount, maturity_date
    - Optional: lender, days_to_maturity, current_rate, refinance_status, evidence_text
    - Example source: "Term Loan A of $50M matures March 15, 2026"
    - Extract: { facility: "Term Loan A", amount: "$50M", maturity_date: "2026-03-15" }

11. interest_rate_reset
    - Description: Variable rate debt approaching reset date
    - REQUIRED fields: facility, current_rate, reset_date
    - Optional: lender, projected_rate, notional_amount, annual_impact, evidence_text
    - Example source: "Revolving facility resets Feb 1, currently at SOFR+150bps"
    - Extract: { facility: "Revolving Credit", current_rate: "SOFR+150bps", reset_date: "2026-02-01" }

12. bank_account_anomaly
    - Description: Unusual activity detected in bank account
    - REQUIRED fields: account, anomaly_type, amount
    - Optional: bank, expected_pattern, transaction_date, evidence_text
    - Example source: "$2.5M wire received from unknown sender on Operating Account"
    - Extract: { account: "Operating Account", anomaly_type: "unknown_sender", amount: "$2.5M" }

=== EXTRACTION RULES ===

1. ONLY use signal types from the list above
2. ALWAYS extract ALL required fields - use null if not explicitly stated
3. Preserve exact values with units as stated in document
4. Include source_spans pointing to exact quoted text
5. Be honest with confidence scores - lower is better than guessing
